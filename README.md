# Dashboard Primavera–Verano 2026–2027 — SSVQP

Dashboard HTML interactivo autónomo basado en 66 respuestas de la lista de chequeo Google Forms de preparación Primavera–Verano 2026–2027.

## Publicación en GitHub Pages

1. Crea un repositorio en GitHub (por ejemplo `dashboard-verano-ssvqp`).
2. Sube `index.html` a la raíz del repositorio (puedes subir también este `README.md`).
3. En **Settings → Pages**, selecciona **Deploy from a branch**, rama **main**, carpeta **/(root)** y guarda.
4. GitHub Pages mostrará la dirección pública una vez publicado.

## Uso

Abre `index.html` directamente en un navegador. No requiere servidor, instalación, librerías externas ni conexión a internet. Los filtros, gráficos y exportación CSV funcionan localmente.

## Fuente y advertencias

Fuente: archivo «Respuestas Lista de Chequeo Primavera–Verano 2026–2027 (1).xlsx», 66 registros. El dashboard refleja una fotografía de los datos al momento de su creación: subir un nuevo Excel a GitHub no actualiza automáticamente los datos embebidos.

**Privacidad:** antes de publicar en un repositorio público, revisa que los datos integrados en `index.html` (incluidas observaciones y responsables) sean aptos para difusión pública. GitHub Pages puede hacer el contenido accesible a terceros.
